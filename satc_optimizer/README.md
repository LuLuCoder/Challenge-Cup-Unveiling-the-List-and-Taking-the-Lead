# SATC-NSGA-II：代理辅助热约束多目标优化

对原单文件脚本 `../optmiser.py` 的工程化重构。
基于论文真实实验数据（Xie et al., 2024，
连续碳纤维增强复合材料 3D 打印工艺参数优化），
用高斯过程回归（GPR）代理模型预测未实验参数组合，
再做多目标 Pareto 优化并给出推荐方案。

## 功能

- 使用论文 Table 3/4 的 9 组真实实验数据训练 GPR 代理模型；
- 对 3×3×3×3 = 81 组离散参数组合预测三个目标
  （ΔT 拉伸偏差、ΔB 弯曲偏差、ΔS 层剪偏差，全部最小化）；
- 9 组真实实验点使用真实目标值，72 组未实验点使用 GPR 预测值，
  不将预测结果冒充真实实验数据；
- 热约束检查（喷嘴温度 [180, 220] °C）+ Pareto 前沿 + 折中推荐；
- 与论文最优方案（A3B2C1D3）比较并输出支配关系；
- 论文方案也按与前沿解相同的归一化基准给出综合评分，便于对比；
- 支持自定义目标权重（ΔT/ΔB/ΔS）：GUI 直接填写，
  命令行使用 `--weights 0.3 0.3 0.4`，默认等权；
- 支持根据 ANSYS 力学结果自动设置权重：导入节点点云、
  六应力分量与变形结果，按拉伸/弯曲/层间剪切失效风险占比
  自动得到 ΔT/ΔB/ΔS 权重（文件格式与 ANSYS 路径规划项目一致）；
- 输出日志与 4 个 CSV（LOO、81 组全预测、Pareto、摘要）。
- 提供 tkinter 图形界面（`python app.py`），
  展示摘要、LOO 指标、81 组预测表、Pareto 前沿表、
  可视化图表与运行日志；命令行版本 `python main.py` 保留。

## 安装与运行

```bash
pip install -r requirements.txt
python main.py
```

指定目标权重（顺序为 ΔT ΔB ΔS）：

```bash
python main.py --weights 0.3 0.3 0.4
```

根据 ANSYS 力学结果自动设置权重：

```bash
python main.py --auto-weights \
  --node-file nodes.csv \
  --stress-folder stress/ \
  --deform-file deform.txt
```

## 自动权重（ANSYS 力学信息）

权重可由力学结果自动确定，三类暴露度：

- 拉伸暴露度：最大主应力 σ1 的正值部分（拉应力水平），
  来自六应力分量文件；
- 弯曲暴露度：总变形量（挠度）；若缺少变形文件，
  用沿打印方向（默认 Z）各层平均 σ1 的变化幅度近似；
- 层间剪切暴露度：层间剪应力 sqrt(τ_xz² + τ_yz²)，
  来自六应力分量文件。

暴露度 = mean((v / v_max)²)，突出高应力区占比；
权重 = 三类暴露度归一化。缺少应力/变形数据时，
对应指标沿用已计算指标的平均暴露度作为基准（并给出提示）。

GUI 中点击"从ANSYS自动设权重"，在弹出的文件对话框中
按住 Ctrl/Shift 多选：节点坐标文件、X~XZ 六个应力分量文件、
变形文件（应力与变形可省略），程序自动按文件名和内容分类，
填充权重并给出依据说明；识别不了或缺少文件时会明确提示。
文件名大小写、首尾空格均兼容，六个应力文件也不再要求在同一文件夹。

## 图形界面

```bash
python app.py
```

界面标签页：

- ① 结果摘要：论文方案 vs SATC 推荐方案（均显示综合评分）、
  支配关系、注意事项；
- ② LOO 验证：各目标 MAE / RMSE / R²；
- ③ 81 组预测：完整参数空间结果表，可按真实/预测数据筛选；
- ④ Pareto 前沿：前沿解明细表；
- ⑤ 可视化：Pareto 前沿 3D 散点（标注推荐方案与论文方案）、
  LOO 预测 vs 实际散点；
- ⑥ 运行日志：完整日志内容。

优化在后台线程运行，界面保持响应；输出目录可在界面中修改。
顶部可填写三个目标的权重（默认等权，可一键"重置等权"），
权重框下方标注各权重的物理含义：ΔT＝拉伸偏差、
ΔB＝弯曲偏差、ΔS＝层间剪切偏差（ILSS，层间结合/抗分层）。

## 综合评分（百分制）

- 每个解的三个目标各自按 Pareto 前沿的 [最好, 最差] 归一化到 0~1
  （0 = 该目标前沿最优），按指定权重加权平均得到 0~1 的均衡分；
- 对外统一显示为百分制：`100 × (1 − 均衡分)`，**100 分最好、0 分最差**；
- 前沿内的解评分在 [0, 100] 之间；前沿外的方案（如论文方案）
  可能出现 <0 或 >100 的评分，表示其整体劣于/优于前沿范围，属正常现象。

## GPR 说明

本版本不调用 `sklearn` 的 `GaussianProcessRegressor.predict()`，
而是按标准 GPR 解析公式直接计算预测均值与标准差，
规避 Windows + scipy/BLAS 下小样本预测偶发阻塞的问题。
超参数（RBF length_scale、白噪声）集中在 `satc/config.py`。

## 与原脚本的差异

- 按职责拆分为 `satc/` 包与 `tests/`，入口收敛到 `main.py`；
- 输出统一写入 `results/` 目录，不再散落在脚本目录；
- GPR 内部冗长的逐行日志移到主流程，模型类保持纯净；
- 删除死代码与未使用参数（如摘要函数中未使用的 `pareto_count`）；
- 保留全部算法逻辑与输出列名，结果与原脚本一致。

> 说明：程序名为 NSGA-II，但 81 组空间为穷举枚举，
> 并未实现真正的遗传算法；热约束在现有参数水平下恒可行。
