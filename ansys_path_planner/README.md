# ANSYS 仿真驱动路径规划系统

对原单文件脚本
`../ANSYS_仿真驱动路径规划_应力梯度增强版.py`
的工程化重构：拆分为分层包结构，算法行为保持一致，
并修复了原文件无法运行的问题。

## 功能

- **数据导入**：一次多选节点坐标文件与 X/Y/Z/XY/YZ/XZ 六个应力分量文件，
  按文件名与内容自动识别分类（与 SATC 参数优化器一致）；兼容 ANSYS 常见
  混合格式（逗号+空格、科学计数法、表头少列等），大文件走 pandas C 引擎
  快速解析；
- **应力分析**：按 Node 融合数据，批量矩阵特征分解计算主应力、主方向与
  von-Mises 应力（十几万节点秒级完成）；
- **层式路径规划**：沿切片轴分层，层内生成应力自适应间距的锯齿扫描线
  （高应力区更密），层间顺序连接；穿越空区（无节点）的段自动断开不绘制；
- **相似零件模板映射（免重复仿真）**：
  - 把"真实仿真 + 规划路径"存入模板库；
  - 新零件只导入节点坐标文件，系统自动做形状相似度评判
    （主轴坐标 + 径向距离直方图 L1 距离，阈值可调）；
  - 相似度达标 -> 映射模板应力场并在新零件上按层重规划路径；
  - 未命中 -> 提示提供真实应力文件；
- **GUI**：四个独立 3D 画布（模型几何、应力分析、规划路径、虚拟机械臂），
  只有机械臂画布做实时动画；节点云全量显示（超过 30 万点才降采样）；
  双击任意图弹出放大窗口（机械臂放大窗口为"左：机械臂动画 / 右：零件
  路径完成进度"双窗）；
- **虚拟机械臂**：6 自由度关节臂（基座回转 + 肩/肘/腕俯仰 + 腕偏摆 +
  工具回转），逆解末端精确贴合路径，零件与机械臂整体放大显示；
- **性能**：导入/路径生成在后台线程执行，界面不冻结；路径用 LineCollection
  批量绘制，13.8 万节点导入约 2 秒、规划约 2 秒；
- **保存**：融合 CSV 与路径 CSV。

## 使用流程

1. **建模板**：导入节点坐标 + 六应力分量 ->「自动导入并计算」->「生成路径」
   ->「存入模板库」（命名）；
2. **新零件**：只导入节点坐标文件 ->「自动导入并计算」-> 自动查库：
   - 相似度 >= 阈值：直接得到映射应力场 + 层式路径（状态栏显示命中模板与相似度）；
   - 相似度 < 阈值：提示提供真实应力文件；
3. 双击任意图可放大查看；右下角机械臂图为动画视图。

## 算法说明

1. 六个应力分量组装为 3x3 对称应力张量，特征分解得到主应力与主方向；
2. 最大主应力归一化后控制扫描线间距（高应力 -> 小间距，更密）；
3. 按切片轴（默认 Z）把节点云分成若干层；
4. 每一层内沿分条轴用自适应间距分条，条内沿扫描轴排序，
   相邻条方向交替，形成连续锯齿扫描线（zigzag）；
5. 层与层按顺序连接，输出带 Layer / Segment_Type（层内路径、
   层间过渡）标记的连续路径表；
6. 空区检测：相邻路径段沿直线采样，若中途远离所有节点
   （无零件实体），该段标记为"空区断开"并拆分为新子路径，
   可视化时不再绘制；实体内低应力区域仍全部保留路径。
7. 形状相似度评判：节点云质心归零 + PCA 主轴对齐 + 等比例缩放后，
   统计三个主轴坐标直方图与径向距离直方图，用 L1 距离衡量相似度
   （对点云密度、旋转、镜像不敏感）；
8. 模板映射：命中模板后，把模板应力场按归一化坐标最近邻
   （反距离加权）映射到新零件节点，再调用层式规划器在新零件上
   重新生成分层路径，保证输出仍是 3D 打印的层式结构。

> 旧版"沿最大主应力方向追踪流线"的算法保留在
> `generate_surface_path()` / `PathPlanner` 中，GUI 默认改用层式规划。

## 与原脚本的差异

- 修复 `IndentationError`：原脚本 `plot_path` 后多出一段模块级缩进代码，
  导致整个文件无法解析运行；重构时将其功能并入密度路径绘制逻辑。
- 修复 colorbar 堆积：多次生成路径时旧色条会残留在图中，现改为先移除再添加。
- 界面扩展为 2x2 四个独立 3D 画布：左上模型几何（节点云）、
  右上应力分析结果、左下规划路径（仅路径线，密度着色，
  图例放图外右侧不遮挡）、右下虚拟机械臂（6 自由度关节臂动画）。
- 绘图区带横向/纵向滚动条：图形大于可视区域时可用滑块
  滚动查看完整内容（替代原先的滚轮缩放）。
- 删除死代码：`select_result`、未使用的 `target` 变量、多余导入等。
- 所有魔法数字集中到 `path_planner/config.py`，便于统一调参。
- 保留 `merge_ansys_data`（单文件结果模式）作为批处理接口。
